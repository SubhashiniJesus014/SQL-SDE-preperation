INTRODUCTION
------------
SQL functions perform operations on values and return results. This document
covers NULL-handling, conditional, aggregate, string, numeric, date/time,
sorting/grouping, window, type-conversion, and other useful MySQL functions.

1. NULL-HANDLING FUNCTIONS
==========================

A. IFNULL()
Purpose: Returns the replacement value when the first expression is NULL.
Syntax:
    IFNULL(expression, replacement_value)

Example:
    SELECT name, IFNULL(salary, 0) AS salary
    FROM employees;

If salary is NULL, the output is 0. Otherwise, the original salary is returned.
In MySQL, IFNULL() takes exactly two arguments.

B. COALESCE()
Purpose: Returns the first non-NULL expression from a list.
Syntax:
    COALESCE(value1, value2, value3, ...)

Example:
    SELECT COALESCE(NULL, NULL, 100, 200) AS result;
Output: 100

Practical example:
    SELECT COALESCE(phone, email, 'No contact') AS contact
    FROM employees;
It returns phone if available, otherwise email, otherwise 'No contact'.

C. NULLIF()
Purpose: Returns NULL if two expressions are equal; otherwise returns the first.
Examples:
    SELECT NULLIF(10, 10); -- NULL
    SELECT NULLIF(10, 20); -- 10

Common use: avoid division by zero.
    SELECT total_sales / NULLIF(total_orders, 0) AS avg_sales
    FROM sales;
If total_orders is zero, the denominator becomes NULL and the result is NULL.

D. IS NULL and IS NOT NULL
Find missing values:
    SELECT * FROM employees WHERE salary IS NULL;
Find present values:
    SELECT * FROM employees WHERE salary IS NOT NULL;

Do not use = NULL or <> NULL to test NULL. Use IS NULL / IS NOT NULL.
In MySQL, ISNULL(expression) returns 1 if expression is NULL and 0 otherwise.
In SQL Server, ISNULL(expression, replacement) has a different purpose.


2. CONDITIONAL FUNCTIONS
========================

A. IF()
Syntax:
    IF(condition, value_if_true, value_if_false)

Example:
    SELECT name, IF(salary >= 40000, 'High', 'Low') AS salary_level
    FROM employees;

B. CASE WHEN
Useful when several conditions are required.
    SELECT name,
           CASE
               WHEN salary >= 50000 THEN 'High'
               WHEN salary >= 30000 THEN 'Medium'
               ELSE 'Low'
           END AS salary_level
    FROM employees;

CASE WHEN is more flexible than IF() for multiple conditions.


3. AGGREGATE FUNCTIONS
======================

Assume employees has columns name, department, salary.

A. COUNT()
    SELECT COUNT(*) FROM employees;
Counts all rows.

    SELECT COUNT(salary) FROM employees;
Counts non-NULL salary values.

    SELECT COUNT(DISTINCT department) FROM employees;
Counts distinct non-NULL departments.

B. SUM()
    SELECT SUM(salary) AS total_salary FROM employees;
Calculates the total of non-NULL salary values.

C. AVG()
    SELECT AVG(salary) AS average_salary FROM employees;
Calculates the average of non-NULL salary values.

D. MAX() and MIN()
    SELECT MAX(salary) AS highest_salary,
           MIN(salary) AS lowest_salary
    FROM employees;
Returns the largest and smallest salary values.

Find the second-highest distinct salary:
    SELECT DISTINCT salary
    FROM employees
    ORDER BY salary DESC
    LIMIT 1 OFFSET 1;

Return all employee details with that salary:
    SELECT *
    FROM employees
    WHERE salary = (
        SELECT DISTINCT salary
        FROM employees
        ORDER BY salary DESC
        LIMIT 1 OFFSET 1
    );


4. STRING FUNCTIONS
===================

UPPER()        UPPER('hello') = 'HELLO'
LOWER()        LOWER('HELLO') = 'hello'
LENGTH()       LENGTH('SQL') = 3 (counts bytes)
CHAR_LENGTH()  CHAR_LENGTH('SQL') = 3 (counts characters)
CONCAT()       CONCAT('Hi',' ','Bob') = 'Hi Bob'
SUBSTRING()    SUBSTRING('Database',1,4) = 'Data'
LEFT()         LEFT('Database',4) = 'Data'
RIGHT()        RIGHT('Database',4) = 'base'
TRIM()         TRIM(' SQL ') = 'SQL'
LTRIM()        LTRIM(' SQL') = 'SQL'
RTRIM()        RTRIM('SQL ') = 'SQL'
REPLACE()      REPLACE('banana','a','o') = 'bonono'
REVERSE()      REVERSE('hello') = 'olleh'
LOCATE()       LOCATE('a','banana') = 2
INSTR()        INSTR('banana','na') = 3
LPAD()         LPAD('7',3,'0') = '007'
RPAD()         RPAD('7',3,'0') = '700'

Examples:
    SELECT SUBSTRING('Subhashini', 1, 3);
Output: Sub
In MySQL, string positions start at 1.

    SELECT REPLACE('apple', 'p', 'b');
Output: abble

For ordinary English text such as 'Hello', LENGTH() and CHAR_LENGTH()
both return 5. For multibyte characters, LENGTH() counts bytes while
CHAR_LENGTH() counts characters.

6. DATE AND TIME FUNCTIONS
==========================

NOW()              Current date and time: SELECT NOW();
CURDATE()          Current date: SELECT CURDATE();
CURTIME()          Current time: SELECT CURTIME();
YEAR()             YEAR('2026-10-28') = 2026
MONTH()            MONTH('2026-10-28') = 10
DAY()              DAY('2026-10-28') = 28
DAYNAME()          DAYNAME('2026-10-28') = 'Wednesday'
DATEDIFF()         DATEDIFF('2026-10-28','2026-10-25') = 3
DATE_ADD()         DATE_ADD('2026-10-28', INTERVAL 7 DAY)
DATE_SUB()         DATE_SUB('2026-10-28', INTERVAL 1 MONTH)
LAST_DAY()         LAST_DAY('2026-02-10') = '2026-02-28'
TIMESTAMPDIFF()    TIMESTAMPDIFF(YEAR,'2000-01-01','2026-01-01') = 26

Find employees hired after January 1, 2025:
    SELECT * FROM employees WHERE hire_date > '2025-01-01';

Find employees hired during 2025:
    SELECT *
    FROM employees
    WHERE YEAR(hire_date) = 2025;

For large tables, a date range can often use an index more effectively:
    SELECT *
    FROM employees
    WHERE hire_date >= '2025-01-01'
      AND hire_date < '2026-01-01';


7. SORTING AND GROUPING CLAUSES
===============================

These are clauses, not functions, but are essential in SQL interviews.

ORDER BY: sorts rows.
    SELECT *
    FROM employees
    ORDER BY department ASC, salary ASC;
SQL sorts by department first, then salary within each department. ASC is the
default ascending order.

GROUP BY: groups rows with matching values.
    SELECT department, AVG(salary) AS avg_salary
    FROM employees
    GROUP BY department;

HAVING: filters groups after aggregation.
    SELECT department, AVG(salary) AS avg_salary
    FROM employees
    GROUP BY department
    HAVING AVG(salary) > 40000;

LIMIT: restricts the number of returned rows.
    SELECT * FROM employees ORDER BY salary DESC LIMIT 3;

DISTINCT: removes duplicate result rows.
    SELECT DISTINCT department FROM employees;

Top three distinct salary values:
    SELECT DISTINCT salary
    FROM employees
    ORDER BY salary DESC
    LIMIT 3;

WHERE filters rows before grouping. HAVING filters groups after GROUP BY.


8. WINDOW FUNCTIONS
===================

Window functions calculate values across related rows without collapsing
them into one row per group.

ROW_NUMBER(): gives each row a unique sequential number.
RANK(): tied values share a rank; the next rank is skipped.
DENSE_RANK(): tied values share a rank; no ranks are skipped.
LAG(): retrieves a value from a previous row.
LEAD(): retrieves a value from a following row.
SUM() OVER(): calculates a windowed sum.
AVG() OVER(): calculates a windowed average.
COUNT() OVER(): counts rows within a window.

Example:
    SELECT name, salary,
           ROW_NUMBER() OVER (ORDER BY salary DESC) AS row_num,
           RANK() OVER (ORDER BY salary DESC) AS salary_rank,
           DENSE_RANK() OVER (ORDER BY salary DESC) AS dense_rank
    FROM employees;

If salaries are 50000, 40000, 40000, 30000:

Salary     ROW_NUMBER     RANK     DENSE_RANK
50000      1              1        1
40000      2              2        2
40000      3              2        2
30000      4              4        3

Remember:
ROW_NUMBER(): 1, 2, 3, 4
RANK():       1, 2, 2, 4
DENSE_RANK(): 1, 2, 2, 3

Compare each salary with the previous row:
    SELECT name, salary,
           LAG(salary) OVER (ORDER BY salary DESC) AS previous_salary
    FROM employees;

Running total:
    SELECT name, salary,
           SUM(salary) OVER (ORDER BY id) AS running_total
    FROM employees;

For deterministic ordering when values tie, add a tie-breaker, such as
ORDER BY salary DESC, id ASC.


9. TYPE CONVERSION FUNCTIONS
============================

CAST():
    SELECT CAST('250' AS UNSIGNED) + 50 AS result;
Output: 300

CONVERT():
    SELECT CONVERT('123', UNSIGNED);
Converts to an unsigned integer in MySQL.

DATE_FORMAT():
    SELECT DATE_FORMAT('2026-10-28', '%d-%m-%Y');
Output: 28-10-2026

STR_TO_DATE():
    SELECT STR_TO_DATE('28-10-2026', '%d-%m-%Y');
Parses text into a date.

11. QUICK INTERVIEW REVISION
============================

1. Replace NULL with 0:
       IFNULL(column, 0)

2. Return the first non-NULL value:
       COALESCE(value1, value2, value3)

3. Avoid division by zero:
       value / NULLIF(denominator, 0)

4. Count all rows:
       COUNT(*)

5. Find the second-highest distinct salary:
       SELECT DISTINCT salary
       FROM employees
       ORDER BY salary DESC
       LIMIT 1 OFFSET 1;
   Another option is DENSE_RANK() over salary descending.

6. Find duplicate values:
       SELECT column_name, COUNT(*)
       FROM table_name
       GROUP BY column_name
       HAVING COUNT(*) > 1;

7. Find the top three distinct salary values:
       SELECT DISTINCT salary
       FROM employees
       ORDER BY salary DESC
       LIMIT 3;

8. Assign ranks without gaps:
       DENSE_RANK() OVER (ORDER BY salary DESC)

9. Extract the year from a date:
       YEAR(date_column)

10. Combine two strings:
        CONCAT(string1, string2)


12. IMPORTANT INTERVIEW REMINDERS
=================================

- IFNULL() is a MySQL function that takes two arguments.
- COALESCE() returns the first non-NULL expression and can take multiple
  arguments.
- NULLIF(a, b) returns NULL when a equals b.
- Test NULL values with IS NULL or IS NOT NULL, not = NULL.
- COUNT(*) counts rows; COUNT(column) ignores NULL values in that column.
- SUM() and AVG() ignore NULL values.
- WHERE filters rows; HAVING filters grouped results.
- ORDER BY column1 ASC, column2 ASC sorts by the first column, then uses the
  second column to break ties in the first.
- LEFT JOIN preserves all rows from the left table; RIGHT JOIN preserves all
  rows from the right table.
- RANK() skips rank numbers after ties; DENSE_RANK() does not.
- Check which SQL dialect the question uses. Some functions differ between
  MySQL, PostgreSQL, SQL Server, and Oracle.
- Learn the purpose and use cases of functions instead of memorizing every
  function at once.
